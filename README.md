# RD-Profile

Personal portfolio for Rajesh Dammala — Technical Support Engineering Leader.

A modern, responsive single-page portfolio showcasing 16+ years of experience building and scaling technical support organizations at Microsoft and IBM. Designed for Director, VP, and C-level Technical Support Engineering leadership opportunities.

## Live Site

🔗 [https://rdammala.github.io/RD-Profile/](https://rdammala.github.io/RD-Profile/)

## Features

- Responsive dark-themed design (mobile-first)
- Sections: About, Leadership Competencies, Experience, Impact, Strategic Initiatives, Philosophy, Contact
- Smooth scroll navigation with active state highlighting
- Intersection Observer animations
- ATS-friendly content structure
- No external dependencies (pure HTML/CSS/JS + Google Fonts)

## Tech Stack

- HTML5, CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (no frameworks)
- Google Fonts (Inter)
- GitHub Pages hosting

## Deployment

Hosted via GitHub Pages from the `main` branch root.
